# Archived documents

This directory contains documents that no longer reflect the current
positioning or implementation of openMiura. They are kept here for
historical reference rather than as active guidance.

## Contents

- **Legacy marketing material** —
  `openMiura_one_pager_commercial.md`,
  `ROADMAP_24M_PRODUCT_STRATEGY.md`,
  `openMiura_agent_control_plane.md`,
  `media/medium_article_*.md`,
  `stable_release_final_pack.md`.
  Written when the public framing of the project was different and
  the "OpenClaw" narrative was central. Preserved intact as evidence
  of the original framing.
- **`refactor/`** — closure artefacts of the previous internal
  refactor of the (then `openmiura/application/openclaw/`, now
  `openmiura/application/runtime_adapters/external/`) module. The
  contents reference the legacy module path because that was the
  real path when those notes were written.

For the current public positioning of openMiura, see the top-level
[`README.md`](../../README.md) and the master plan in
[`CLAUDE.md`](../../CLAUDE.md).
